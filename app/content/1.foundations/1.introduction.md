## 1. What is Python?

Python is a **programming language**. A programming language is just a way for humans to give instructions to a computer.

Think of it like this:

- You speak English (or Telugu, Hindi, Spanish, etc.) to talk to people.
- You use Python to talk to a computer.

Python was created by a man named **Guido van Rossum** in the year **1991**. Fun fact: he did not name it after the snake. He named it after a British comedy show called "Monty Python's Flying Circus" because he wanted the language to be fun to use.

### Why is Python so popular?

- It reads almost like normal English.
- It is short and clean. You can do in 2 lines what other languages do in 10 lines.
- It is free. Anyone can download and use it.
- A huge community of people uses it, so help is always one Google search away.

### The Zen of Python (The Philosophy)

Python has a small set of rules that guide how the language is designed. These rules are called **The Zen of Python**. You can even see them inside Python itself by typing `import this`.

Here are the most important ideas in simple words:

- **Beautiful is better than ugly.** Write clean code.
- **Simple is better than complex.** Don't make things harder than they need to be.
- **Readability counts.** Your code should be easy for other people (and future you) to read.
- **There should be one obvious way to do it.** Don't confuse people with 10 different styles.
- **If the code is hard to explain, it is a bad idea.** Good code is easy to explain.

Keep these in mind as you learn. They will make you a better coder.

## 3. Installing Python

Before we can write Python code, we need to install it on our computer. Here is how to do it based on the system you are using.

### For Windows Users

1. Open your web browser and go to **https://www.python.org/downloads**
2. Click the big yellow button that says **"Download Python 3.x.x"** (the latest version).
3. Once the file is downloaded, double-click it to start the installer.
4. **IMPORTANT:** At the bottom of the installer window, tick the box that says **"Add Python to PATH"**. This is a very common step that people forget, and it causes problems later.
5. Click **"Install Now"** and wait for it to finish.
6. Click **"Close"** when done.

To check if Python was installed correctly:

- Open **Command Prompt** (press the Windows key, type `cmd`, and press Enter).
- Type `python --version` and press Enter.
- If you see something like `Python 3.12.1`, you are good to go!

### For Mac Users

Mac usually comes with an old version of Python, but we want the latest one.

1. Go to **https://www.python.org/downloads**
2. Download the macOS version.
3. Open the downloaded `.pkg` file and follow the steps.
4. Once done, open the **Terminal** app.
5. Type `python3 --version` and press Enter.
6. You should see the version number.

You can also use **Homebrew** (if you have it installed):

```
brew install python
```

### For Linux Users

Most Linux systems already have Python. To check, open your **Terminal** and type:

```
python3 --version
```

If it is not installed or you need a newer version:

**On Ubuntu/Debian:**

```
sudo apt update
sudo apt install python3
```

**On Fedora:**

```
sudo dnf install python3
```

**On Arch:**

```
sudo pacman -S python
```

## 4. Setting Up an IDE (Your Writing Tool)

An **IDE** stands for **Integrated Development Environment**. It is just a fancy name for the app where you will write your Python code. Think of it like Microsoft Word, but for code.

You can write Python in a basic text editor, but IDEs make life much easier. They:

- Highlight your code with colors so it is easy to read.
- Tell you when you make a mistake.
- Help you run your code with one click.
- Suggest the next word while you type (like auto-complete).

Here are the three most popular choices:

### 1. VS Code (Recommended for Beginners)

**Visual Studio Code** is free, light, and works well on any computer. Most people use this.

How to set it up:

1. Download it from **https://code.visualstudio.com**
2. Install it (just keep clicking Next).
3. Open VS Code.
4. On the left side, click the **Extensions** icon (it looks like four small squares).
5. Search for **"Python"** and install the official extension made by Microsoft.
6. Done! You are ready to code.

### 2. PyCharm

**PyCharm** is made by a company called JetBrains. It is a powerful tool built only for Python.

- **Community Edition** is free.
- **Professional Edition** is paid, but you only need it for advanced things like web development.

Download from **https://www.jetbrains.com/pycharm**

PyCharm is heavier than VS Code, so it might feel slow on old computers. But it has amazing features once you get used to it.

### 3. Jupyter Notebook

**Jupyter Notebook** is different from the other two. Instead of writing a full program, you write code in small chunks called **cells** and run them one at a time.

This is very popular for:

- Data science
- Learning and experimenting
- Showing results with charts and text together

How to install it (easiest way):

1. Install **Anaconda** from **https://www.anaconda.com/download**
2. Anaconda comes with Python, Jupyter Notebook, and many data science tools — all in one package.

You can also install it using pip:

```
pip install notebook
```

Then run it by typing:

```
jupyter notebook
```

### Which one should you pick?

- **Just starting out?** Use **VS Code**.
- **Want the most powerful tool?** Use **PyCharm**.
- **Interested in data science?** Use **Jupyter Notebook**.

You can try all three later and pick your favorite.

## 5. Using the Python Interpreter (REPL)

The Python interpreter is the brain that reads and runs your code. It comes built-in when you install Python.

**REPL** stands for:

- **R**ead — it reads what you type
- **E**valuate — it figures out what you want
- **P**rint — it shows you the answer
- **L**oop — it waits for your next command

Think of it like a calculator that understands Python.

### How to open the REPL

**On Windows:** Open Command Prompt and type `python`
**On Mac/Linux:** Open Terminal and type `python3`

You will see something like this:

```
Python 3.12.1 (main, Dec  7 2025, 12:00:00)
Type "help", "copyright", "credits" or "license" for more information.
>>>
```

Those three arrows `>>>` mean Python is ready and waiting for you.

### Try it out

Type these commands one by one and press Enter after each:

```python
>>> 2 + 2
4

>>> 10 * 5
50

>>> print("Hello")
Hello

>>> name = "Yaswanth"
>>> print("Hi", name)
Hi Yaswanth
```

See? The computer listens and responds right away. This is a great way to test small ideas.

To exit the REPL, type `exit()` and press Enter, or press **Ctrl + Z** on Windows (then Enter) or **Ctrl + D** on Mac/Linux.

## 6. Your First Program: Hello, World!

There is a tradition in programming. The first program you write in any new language is one that prints the words **"Hello, World!"** on the screen. Let's follow the tradition.

### Step 1: Create a new file

1. Open VS Code (or any IDE you picked).
2. Click **File → New File**.
3. Save it as **hello.py** in any folder you like.

The `.py` at the end is very important. It tells the computer that this is a Python file.

### Step 2: Write the code

Type this single line into the file:

```python
print("Hello, World!")
```

### Step 3: Save the file

Press **Ctrl + S** (or **Cmd + S** on Mac).

### Step 4: Run the program

**Option A — Using the IDE:**
In VS Code, click the small **"Play" (▶) button** at the top-right of the screen.

**Option B — Using the terminal:**

1. Open a terminal.
2. Go to the folder where you saved the file:
   ```
   cd path/to/your/folder
   ```
3. Run the program:
   ```
   python hello.py
   ```
   (Or `python3 hello.py` on Mac/Linux.)

### What you should see

```
Hello, World!
```

Congratulations! You just wrote and ran your first Python program.

### What happened here?

Let's break the code down:

- `print` is a **function**. A function is a small task that Python knows how to do. The `print` function's job is to show something on the screen.
- `( )` are **round brackets**. Whatever you put inside these brackets gets sent to the function.
- `"Hello, World!"` is a **string**. A string is just text. Text in Python must always be inside quotes (`"..."` or `'...'`).

So in plain English: _"Hey Python, please print the words Hello, World! on the screen."_

## 7. Understanding .py Files and How Python Runs Them

When you save a file with the `.py` ending, you are telling your computer: _"This file contains Python code."_

### The Life of a Python Program

Here is what happens, step by step, when you run a `.py` file:

1. **You write code** in a `.py` file using your IDE.
2. **You run the file** by typing `python filename.py` or clicking the Play button.
3. **Python reads your file** line by line, from top to bottom.
4. **Python converts your code** into a form the computer can understand. This in-between form is called **bytecode** (`.pyc` files).
5. **The Python Virtual Machine (PVM)** runs the bytecode.
6. **You see the output** on the screen.

You do not need to worry about steps 4 and 5. Python handles it all behind the scenes. Just remember: **you write code → Python runs code → you see result**.

### A few important rules about Python files

- The file name must end with `.py`.
- Do not use spaces in file names. Use `hello_world.py` instead of `hello world.py`.
- Do not start a file name with a number. `1hello.py` will cause trouble later when you import files.
- Keep names short and meaningful. `calculator.py` is better than `my_first_python_program_calculator.py`.

### Script files vs. the REPL

- **REPL:** Good for quick tests and trying ideas.
- **Script file (`.py`):** Good for real programs you want to save and run again.

Most of the time, you will write code in `.py` files. Use the REPL when you just want to check something fast.
