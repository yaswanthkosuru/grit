# Migrate from Windows to Ubuntu

> Most professional Python work happens on Linux. Servers run Linux, Docker images are Linux, most tutorials assume Linux. Switching your daily driver to Ubuntu is one of the biggest setup decisions you can make for a serious Python journey.

You don't have to delete Windows. The clean path is **dual boot** — Windows stays on the drive, Ubuntu installs beside it, and you pick which one to use when you turn the laptop on.

> ⏱ **Time:** 10–20 minutes once your USB is ready.
> 📦 **You'll need:** an 8 GB+ USB pendrive, ~25 GB free disk space, your charger plugged in.

---

## Step 1 — Make a bootable Ubuntu USB

1. Download the Ubuntu ISO from <https://ubuntu.com/download/desktop>. Pick the latest **LTS** version.
2. Download Rufus from <https://rufus.ie> (single `.exe`, no install).
3. Plug in the pendrive (anything on it will be erased).
4. Open Rufus → **Device** = your USB, **Boot selection** = the Ubuntu ISO.
5. **Partition scheme** = `GPT`, **Target system** = `UEFI`. Leave the rest default.
6. Click **START** → choose **ISO Image mode** → wait until it says **READY**.

---

## Step 2 — Back up your files

Copy your important files (Documents, Desktop, photos, project folders) to an external drive or cloud. Anything that touches partitions has a small risk — don't skip this.

Also save your Wi-Fi password and any Windows app license keys somewhere outside the laptop.

---

## Step 3 — Disable Secure Boot in BIOS

1. Shut down the laptop.
2. Power on and **tap the BIOS key** repeatedly:

   | Brand                | Key             |
   | -------------------- | --------------- |
   | Dell                 | `F2` or `F12`   |
   | HP                   | `F10` or `Esc`  |
   | Lenovo / ThinkPad    | `F1` or `F2`    |
   | Acer                 | `F2`            |
   | Asus                 | `F2` or `Del`   |
   | MSI                  | `Del`           |
   | Samsung              | `F2`            |
   | Surface              | hold **Volume Up** + power |

3. In BIOS, find **Security** or **Boot** → set **Secure Boot** to `Disabled`.
4. Press **F10** to **Save and Exit**.

> If tapping the BIOS key isn't working, you can reach UEFI from inside Windows: **Settings → System → Recovery → Advanced startup → Restart now → Troubleshoot → Advanced options → UEFI Firmware Settings → Restart**.

---

## Step 4 — Restart and boot from the USB

1. Plug the bootable USB in.
2. Restart the laptop and tap the **boot menu key** (usually `F12`, `F9`, `Esc`, or `F11`).
3. From the boot menu, pick your USB drive (e.g. `UEFI: SanDisk USB`).
4. On Ubuntu's purple **GRUB** screen, press **Enter** on `Try or Install Ubuntu`.

After ~30 seconds you'll be in a *live* Ubuntu desktop — nothing is saved yet. Double-click **Install Ubuntu** to start the installer.

---

## Step 5 — Install Ubuntu alongside Windows

1. Pick your **language** and **keyboard layout**.
2. Connect to **Wi-Fi**.
3. Choose **Normal install**, tick *Download updates* and *Install third-party software*.
4. **Installation type** → choose **Install Ubuntu alongside Windows Boot Manager**.
5. Drag the slider to give Ubuntu **50–100 GB** of disk space. Click **Install Now**.
6. Pick your **timezone**.
7. Create your **username and a strong password** — you'll type this password every time you run `sudo`.
8. Wait 15–30 minutes while it installs.
9. When it says **Restart Now**, click it. **Pull out the USB** when prompted, then press Enter.

On the next boot you'll see GRUB — pick **Ubuntu** to start your new system, or **Windows** to go back. You can switch any time.

---

## Step 6 — Install Python and dev tools

Open **Terminal** (`Ctrl + Alt + T`) and run:

```
sudo apt update && sudo apt upgrade -y
sudo apt install -y python3 python3-pip python3-venv git build-essential curl
sudo snap install code --classic
```

Verify everything installed:

```
python3 --version
pip3 --version
git --version
code --version
```

That's it — you're on Linux. Most Python tutorials, Docker, every cloud server you'll ever SSH into all speak this same language.
